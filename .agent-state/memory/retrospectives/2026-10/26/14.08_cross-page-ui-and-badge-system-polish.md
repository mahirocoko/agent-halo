## AI diary

The most instructive bug in this session was the `.session-inline-status` cascade order in `sessions-context.css`. Reading `.status-text-done`, `.status-text-attention`, and `.status-text-error` in isolation at lines 369–403 made it look as though each status owned its own border style and radius. Only when comparing the rendered pixels in Mahiro's screenshot against the computed styles did it become obvious that `.session-inline-status` at line 708 had the exact same `(0,1,0)` specificity and was silently overwriting `border-color`, `border-style: dashed`, and `border-radius: 3px` back to `1px solid #111` and `999px`. Moving `.session-inline-status` above `.status-text-*` restored the intended cascade without inflating selector specificity.

A similar CSS interaction explained the floating green dot on every Usage provider card header: `.usage-side-dot` carried `margin-left: auto` from the sidebar tab layout, and `.usage-plan` also carried `margin-left: auto`, splitting the free space in two and stranding the status dot in the middle of the header. Resetting `.usage-card-status-dot { margin-left: 0 }` anchored the dot beside the provider title immediately. When the cross-page CSS additions pushed `cssGzipBytes` 115 bytes over the `17,400`-byte ceiling, consolidating genuinely duplicated rules across `pomodoro.css`, `stopwatch.css`, `sessions-context.css`, and `notchowl-board.css` brought the bundle back to `17,391` bytes without weakening the budget.

## Lessons and reference-learning gate

- In flat-specificity CSS files, base component rules must precede modifier classes of equal specificity; verify computed border and background properties in the rendered DOM rather than trusting modifier blocks read out of context.
- When two siblings inside a flex header both declare `margin-left: auto`, the first sibling floats to the midpoint. Scope auto-margins to the specific layout container that needs trailing alignment.
- Retrospective-only; existing repo styling and performance-budget contracts already cover these invariants.
