## AI diary

I initially treated a successful battery query, focused unit tests, a build, and browser-local IPC mocks as a sufficiently convincing implementation boundary. The installed control exposed why that was incomplete. The hook intentionally waited for event subscription before reading native status, but the application capability did not permit subscription at all. The mocks accepted a call that the real runtime rejected. My own unsupported-state rendering then hid the useful error, so the person using the app saw a button that looked unavailable rather than a diagnosable permission failure. I should have audited the permission owner before calling the implementation ready to try.

I also let delegation cost more than the task warranted. The writer performed repeated broad reads and a full browser-suite attempt despite a narrow assignment. I intervened, but only after unnecessary delay. Main's source audit was useful: it found concrete deadlock and lifetime hazards that passing mocks did not exercise. Yet those correct findings did not compensate for the missing installed IPC boundary. The eventual correction was small: a main-only listen/unlisten capability, error-first rendering, and one regression guard. Mahiro's instruction to skip Gemini QA for that correction kept the work proportional. I am preserving both the useful native checks and the failed readiness assumption, rather than rewriting this session into an uninterrupted success story.

## Honest feedback

1. **Delegation discipline:** The initial writer drifted into broad exploration and a browser fanout outside its instructions. Sparse steering was not enough to prevent wasted time. A bounded report and narrower native acceptance contract would have been better than collecting a large amount of peripheral baseline evidence.
2. **Evidence independence:** Fresh browser QA was independent of the writer, but its mocked transport still bypassed the native permission boundary. It also misreported a 500px capture as 420px. Independence alone does not establish truth; Main had to inspect pixels and challenge the exact runtime owners.
3. **Closeout accuracy:** The first install was real and hash-verified, but calling the feature ready concealed an unverified native event subscription. The final semantic-only QA correction did not re-query console after interaction; its report was explicitly downgraded rather than promoted to full rendered acceptance. The native ACL fix and later human approval are separate evidence, not retroactive proof that the first QA was correct.

## Lessons learned

Browser IPC mocks establish UI handling, not native capability authorization. Audit compiled capability owners and surface listener errors before unknown-support fallbacks. Preserve serialized consume, callback ownership and durable disarm as distinct native invariants. The current domain document already records the reusable ACL boundary, so no duplicate reference-learning file is promoted by this RRR.
